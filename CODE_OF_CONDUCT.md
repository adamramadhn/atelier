# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/), v2.1.

By participating, you agree to keep discussion about scope, structure, and design decisions —
not people. Harassment, personal attacks, and repeated bad-faith behavior are not accepted.

Project maintainers (the repo owner) moderate issues, PRs, and comments on this repository.
Violations: email the owner via GitHub (@adamramadhn) with links and context. Actions range
from a warning to blocking, proportionate to severity.

This code of conduct applies in all project spaces (issues, PRs, discussions) and covers
contributed material in those spaces.
