# CLAUDE.md

Claude Code entry point for this repository. Routing lives in [AGENTS.md](AGENTS.md) → `skills/design-suite/SKILL.md`; this file only adds Claude Code–specific conventions.

- To use with Claude Code, copy the whole folder to `.claude/skills/design-suite/` — `references/` travels with it; modules are loaded from there on demand, not installed separately.
- Skill bodies under `skills/design-suite/references/` are unedited upstream vendor copies: do not edit, refactor, or "clean up" them; fix routing or docs only at the entry point or repo level. Provenance commits per module are in README.md.
- Do not run two creative modules on the same artifact in one session (see anti-overlap guard in `skills/design-suite/SKILL.md`).
- When working in a project that has a `DESIGN.md`/`PRODUCT.md` generated by the impeccable module, honor it as the pinned design context for that project.
